# Posters, short-drama imagery and ecommerce

Use the user's brief and references to choose a composition. The following are task-specific checks, not fixed page templates or a mandatory approval sequence.

## Posters

Establish the audience, message, exact headline/subheading/details, target aspect ratio and visual hierarchy. Put text into the prompt verbatim, including punctuation and numbers. Describe where each text block belongs, its relative scale and readable contrast, subject placement, negative space, palette and lighting. Chinese copy should remain in Chinese. For reference-led designs, separate content identity from style/composition references. Review spelling, hierarchy, crowded margins and readability at the intended display size.

## Short-drama characters and shots

Create character sheets, scene concepts, storyboards and keyframes as requested. Maintain an explicit identity description covering face, age appearance, hair, costume, recurring props and distinctive features. Assign reference roles by input number; avoid merging two characters. Each shot needs its own action, framing, camera angle, lighting, location and continuity requirements.

For subsequent shots, reuse the original character reference and, when helpful, the latest accepted frame as additional `-i` files. A new Images API request has no implicit memory of the preceding shot. Preserve scene geography, prop hand, clothing and screen direction unless the script calls for changes. Inspect every character and frame; report identity drift. Still frames or GIFs are not a completed dialogue video with voice, sound and editing.

## Ecommerce

Inspect the product silhouette, part count, colors, seams, controls, logos and packaging. Identify which references show the same SKU and which are style examples. Bind material, dimensions, specifications, certification, performance and commercial promises to user-provided or verified product facts. Fill information gaps with useful visual/design descriptions, never invented performance claims.

Plan each requested placement and page purpose, such as search image, gallery, detail, SKU or lifestyle use. Select dimensions for that placement; verify platform rules when claiming compliance. For a set, give each page a distinct buying question and avoid repeating a decorative still life. Describe product scale, focal point, text zone and reading order. A front/back comparison depicts repeat views of one product unless the package actually contains two units.

Pass the actual product files via `-i` for new environments, alternate compositions and edits. View-generated unseen construction remains an inference and needs checking. Inspect shape, proportions, hardware, color, count, text and factual claims against the references. Show unresolved differences rather than marking the set accepted automatically.
